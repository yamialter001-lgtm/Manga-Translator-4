# Manga Translator (ใช้ส่วนตัว)

แอป Android แปลมังงะ/มังฮวา/เว็บตูนเป็นภาษาไทย ทำงานตามขั้นตอนของ ToriiTranslate (หน้า Image)
แต่ตัดระบบ login และเครดิตออก — ใช้ Gemini API Key ของคุณเอง

**ภาษาต้นฉบับ:** ญี่ปุ่น · อังกฤษ · เกาหลี · จีนตัวเต็ม · จีนตัวย่อ (หรือตรวจจับอัตโนมัติ) → **ไทย**
**โมเดล:** หลัก `gemini-3.5-flash-lite` · สำรอง `gemini-3.8-flash` (เปลี่ยนได้ในหน้าตั้งค่า)
**ฟอนต์:** Itim · Kodchasan · FiraGO (+ นำเข้าไฟล์ .ttf/.otf เองได้)

## สร้าง APK บน GitHub

1. สร้าง repository ใหม่ (แนะนำ **Private**) แล้วอัปโหลดไฟล์ในโฟลเดอร์นี้ทั้งหมด
   (ต้องมี `.github/`, `signing/`, `scripts/`, `android-overrides/`, `src/`)
2. ไปที่แท็บ **Actions → Build APK → Run workflow**
   (หรือ push tag เช่น `git tag v1.0.0 && git push --tags`)
3. รอประมาณ 10–15 นาที → ไฟล์ `.apk` จะอยู่ที่ **Releases** (และใน Artifacts ของ workflow)
4. ดาวน์โหลดลงมือถือ → ติดตั้ง (อนุญาต “ติดตั้งแอปที่ไม่รู้จัก”)
5. เปิดแอป → ⚙ ตั้งค่า → ใส่ API Key → กด **ทดสอบการเชื่อมต่อ**

**ลายเซ็น APK:** ใช้ `signing/release.jks` (รหัสผ่าน `mangatranslator`, alias `manga`) เพื่อให้ติดตั้งอัปเดตทับเวอร์ชันเดิมได้
ถ้าต้องการใช้คีย์ของตัวเอง ให้ตั้ง Secrets: `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`

## วิธีใช้

1. **โปรเจกต์ใหม่** → ตั้งชื่อ ภาษาต้นฉบับ ทิศทางการอ่าน
2. **นำเข้า** รูปภาพ หรือไฟล์ CBZ / ZIP (เรียงชื่อไฟล์ตามตัวเลขอัตโนมัติ)
3. ใส่ตัวละคร/คำศัพท์ใน 📖 **บริบทและคำศัพท์** (ไม่บังคับ แต่ช่วยให้ชื่อและสรรพนามสม่ำเสมอ)
4. **แปลทั้งหมด** หรือเปิดหน้าแล้วกด **แปลหน้านี้**
5. แก้ไขในตัวแก้ไข: แตะกล่อง → แก้คำแปล/ฟอนต์/ขนาด/สี/ขอบ, ลากย้าย–ปรับขนาดกรอบ
   (กรอบแดงประ = พื้นที่ลบข้อความเดิม, กรอบน้ำเงิน = พื้นที่วางข้อความไทย), Undo/Redo
6. **ส่งออก** เป็น CBZ/ZIP (บันทึกที่ `Download/MangaTranslator`) หรือบันทึกภาพทีละหน้า

## รูปแบบข้อมูลที่ส่งให้ Gemini

ดูของจริงได้ที่ ตั้งค่า → “ดูรูปแบบข้อมูลที่ส่งให้ Gemini” (โค้ดอยู่ที่ `src/lib/gemini.ts`)

| ส่วน | เนื้อหา |
|------|---------|
| 1. Original Image | ภาพหน้ามังงะ (JPEG, ย่อด้านยาวสุดตามตั้งค่า) |
| 2. OCR Text | ข้อความจาก ML Kit ในเครื่อง พร้อม `id` และ `box_2d` [ymin,xmin,ymax,xmax] สเกล 0–1000 |
| 3. Context / Glossary | เรื่องย่อ, ตัวละคร (ชื่อ/เพศ/สรรพนาม), คำศัพท์ที่เกี่ยวข้อง, สรุปและบทพูดหน้าก่อนหน้า |
| 4. Translation Instructions | ภาษาต้นฉบับ → ไทย, ทิศทางการอ่าน, น้ำเสียง, คำลงท้ายชื่อ, ขอบเขต, พรอมต์เพิ่มเติม |

Gemini ตอบกลับเป็น JSON ตาม schema: `page_summary` และ `regions[]` ที่มี `order`, `ocr_ids`, `kind`, `source_text`,
`translation`, `box_2d` (กรอบข้อความเดิม) และ `bubble_box_2d` (พื้นที่วางข้อความไทย)

**การสลับโมเดล:** 429 / 5xx / timeout → ลองใหม่ (exponential backoff) แล้วสลับไปโมเดลสำรอง ·
ไม่พบโมเดล/ถูกบล็อก → ใช้โมเดลสำรองทันที · API Key ผิด → แจ้งเตือนและไม่สลับ · โควต้าหมดทั้งคู่ → หยุดงานทั้งชุด

## ข้อจำกัดที่ควรรู้

- ไม่มีการนำเข้า/ส่งออก PDF, PSD และเครื่องมือแปรง (brush) แบบ Torii — มีลบข้อความอัตโนมัติ (เติมสีพื้น/ไล่สีจากขอบ)
  ซึ่งดีกับกรอบคำพูดพื้นเรียบ แต่ข้อความบนลายภาพอาจเห็นร่องรอย ปรับด้วย “พื้นที่ลบ” และ “พื้นหลังที่ลบ”
- OCR ใช้ Google ML Kit (ญี่ปุ่น/เกาหลี/จีน/ละติน) ถ้าอ่านไม่ได้แอปจะให้ Gemini อ่านจากภาพเอง
- FiraGO ดาวน์โหลดตอน build (ถ้าไม่สำเร็จจะใช้ Kodchasan แทน) — ตรวจว่าฟอนต์รองรับอักษรไทยก่อนใช้
- ชื่อไฟล์ `.cbz` บางเครื่อง Android อาจเติม `.zip` ต่อท้าย ให้เปลี่ยนชื่อเอง
- โปรเจกต์เก็บใน IndexedDB ของแอป (ลบข้อมูลแอปแล้วหาย) — ส่งออก CBZ เก็บไว้เป็นสำรอง
